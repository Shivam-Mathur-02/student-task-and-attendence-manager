# Student Task & Attendance Manager

## 1. Product Overview

A web application that helps college students manage academic subjects, track attendance, organize assignments, and monitor academic progress through a centralized dashboard.

## 2. Problem Statement

Students often manage attendance records and assignment deadlines separately. This makes it difficult to monitor attendance shortages, prioritize tasks, and maintain an overview of academic progress.

Our application provides a centralized solution.

## 3. Target Users

* College students
* Undergraduate students
* Students managing multiple subjects and assignments

## 4. Core Features

### Dashboard

* Total subjects
* Overall attendance percentage
* Pending tasks
* Completed tasks
* Low-attendance warnings

### Subject Management

* Add subjects
* View subjects
* Delete subjects

### Attendance Management

* Record attended classes
* Record total classes
* Calculate attendance percentage
* Display attendance progress
* Highlight attendance below 75%

### Task Management

* Create academic tasks
* Associate tasks with subjects
* Set deadlines
* Set priorities
* Mark tasks as completed
* Delete tasks

### Student Profile

* Display student information
* Edit profile information

## 5. Minimum Viable Product

The first version must support:

1. Dashboard
2. Subject management
3. Attendance tracking
4. Attendance calculations
5. Task management
6. Data persistence
7. Navigation between pages

## 6. Success Criteria

* All core pages work.
* Subjects can be added and deleted.
* Attendance percentages are calculated correctly.
* Tasks can be created, completed, and deleted.
* Dashboard statistics reflect actual data.
* Data survives a browser refresh.
* The application works on desktop and mobile.

## 7. Out of Scope

For the initial version, avoid email verification, password recovery, real-time notifications, and advanced analytics.
